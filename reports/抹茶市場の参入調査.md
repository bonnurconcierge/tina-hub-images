# 抹茶市場は外需が国内供給を追い越す転換点に立つ

**エグゼクティブサマリー（要約）**
抹茶市場は2024〜2026年に「世界的な需要爆発と国内供給の硬直」が正面衝突し、**原料である碾茶（てんちゃ）の価格が京都で2年連続約1.7倍（2025年初入札8,235円/kg→2026年14,127円/kg）**に跳ね上がった売り手市場にある。日本の緑茶輸出額は**2025年に720.9億円（前年比+98.2%）**と倍増し、その**84%（603.8億円）を抹茶を含む粉末状緑茶**が占める一方、国内の抹茶市場は業界推計で300〜400億円にとどまり、抹茶はすでに「内需より外需」の商品になった（[食品産業新聞社](https://shokuhin.net/139433/2026/02/18/inryou/inryou-inryou/%E6%97%A5%E6%9C%AC%E8%8C%B6/)、[抹茶タイムズ](https://matcha-times.jp/2025/06/11/matcha-market-2025/)）。主な顧客は食品・飲料メーカー、カフェ・外食チェーン、海外輸入商社・D2C、国内外の消費者、インバウンド観光客で、全セグメントに共通する課題は「買えない・高い・本物か分からない」である。市場はプレミアム帯（京都・宇治ブランド、石臼挽き、茶道用）と業務用帯（鹿児島・静岡の機械粉砕、ラテ・菓子原料）に二極化し、後者では**中国（2025年生産1.2万t超、世界の約7割との中国側主張）**が単価4〜5分の1で代替圧力を強めている。収益面では、カフェは抹茶粉の原価が1杯数十円〜百数十円で粗利7〜8割と最も転嫁しやすく、逆に問屋・製茶業と大手飲料（伊藤園の営業利益率4.4%）に原料高のダメージが集中している。新規参入の現実的な選択肢は、(a) 茶園・碾茶工場を押さえる川上の垂直統合（商社・JAが先行）、(b) 後継者不在の老舗問屋のM&A、(c) 体験・産地直結で差別化した抹茶カフェ、(d) 業務用の安定調達窓口やB2B集約、(e) 有機・GI・トレーサビリティを武器にした欧米向け輸出であり、「問屋から高級抹茶を仕入れて売る」だけの参入は2026年時点では事実上不可能に近い。なお本レポートの数値には調査環境の制約で一次資料を直接確認できなかったものが多く、該当箇所は【要確認】と明記した。

## 用語解説（初めて読む方向け）

| 用語 | 意味 |
|---|---|
| **碾茶（てんちゃ）** | 抹茶の原料。茶園を摘採前に20日以上覆って日光を遮り（覆下栽培）、摘んだ葉を蒸したあと「揉まずに」乾燥させた茶葉。これを粉にすると抹茶になる |
| **覆下栽培（おおいしたさいばい）** | よしず・寒冷紗などで茶園を覆う栽培法。渋みを抑え旨味と鮮やかな緑色を出すが、樹に負担がかかる |
| **荒茶（あらちゃ）** | 農家や産地工場で一次加工した茶の総称（煎茶・碾茶・玉露などを含む）。問屋が仕入れて仕上げる前の状態 |
| **仕上げ・合組（ごうぐみ）** | 荒茶から茎や葉脈を除き、複数の茶をブレンドして製品にする問屋の工程 |
| **石臼（いしうす）挽き** | 花崗岩の臼で碾茶をゆっくり粉砕する伝統製法。1台あたり約40g/時しか挽けない |
| **粉砕機（ハンマーミル・ボールミル等）** | 工業用の高速粉砕機。石臼の数十〜数百倍の処理能力があり、業務用抹茶の主流 |
| **薄茶（うすちゃ）／濃茶（こいちゃ）** | 茶道の飲み方。薄茶は抹茶約2gを湯70mlで泡立てる一般的な飲み方、濃茶は約4gを湯30mlで練る高級品向けの飲み方 |
| **一番茶** | その年最初（4〜5月）に摘む最上級の茶。碾茶はほぼ一番茶から作られる |
| **茶問屋（製茶業者）** | 荒茶を仕入れ、仕上げ・ブレンド・製粉・包装して小売やメーカーに販売する中間業者（丸久小山園・一保堂・あいや等） |
| **セレモニアル／カリナリーグレード** | 海外で使われる「茶道用（高級）」「料理用（加工用）」の区分。公的な基準はなく、業者ごとに意味が異なる |
| **MRL（残留農薬基準値）** | 各国が定める農薬の残留上限。EUは日本より厳しく、未設定の農薬は一律0.01mg/kg |
| **GI（地理的表示）** | 産地と結びついた農産品名を国が保護する制度。2026年7月に「日本茶」が登録された |

## 1. 市場の分解：原料から販路まで5層で捉えると構造が見える

抹茶市場は単一の市場ではなく、**「原料（碾茶）→加工（抹茶粉末）→最終用途→販路→地理」の5層**で分解すると理解しやすい。原料段階では、碾茶は覆下栽培した茶葉を揉まずに乾燥したもの、抹茶は碾茶を茶臼等で微粉末にしたものと日本茶業中央会が定義しているが、これは業界団体の自主基準であり法的な強制力はない（[日本茶業中央会 緑茶の表示基準](https://www.nihon-cha.or.jp/pdf/hyoujikijyun.pdf)）。国際的にはISO 20715:2023が茶の分類の中で抹茶を定義し、工程面ではISO/TR 21380:2022が「遮光→蒸し→揉まずに乾燥→挽砕」と規定している（[note 大木賢](https://note.com/kenohki/n/nc1e5000cb51b)、[Japanomars](https://www.japanomars.com/insights/what-counts-as-real-matcha)）。この「法的定義の弱さ」が、粉末煎茶や中国産粉末が「抹茶」として流通する品質混乱の根本原因になっている。

加工段階では、製粉方法によってプレミアムと業務用が分かれる。石臼挽きは1台あたり約40g/時にすぎず（[祇園辻利](https://www.giontsujiri.co.jp/ujicha/matcha/)）、連続型乾式ボールミルは8〜12kg/時で「茶臼200〜250台分」とメーカーが公表している（[日本コークス工業](https://www.nc-kakouki.co.jp/products-detail/tea-meister-mill/)）。業界関係者の推測では**現在の抹茶の約8割はすでに粉砕機製、石臼挽きは約2割**にとどまる（[桑原善助商店](https://www.zkuwabara.com/mattya4_2.html)）。最終用途は「点てて飲む（薄茶・濃茶）」「ラテ・RTD飲料」「菓子・アイス」「化粧品・サプリ」に分かれるが、加工用と飲用の比率を示す公的統計は存在せず、業界メディアの推計で「加工食品向け約15%」とされるのみである【要確認：定義が不明で、飲料を別枠にしている可能性が高い】（[抹茶タイムズ](https://matcha-times.jp/2026/04/matcha-market-growth/19/)）。消費実態から見ると、2015年の日経調査で抹茶加工品の喫食経験は79.5%（抹茶アイス93.1%）だったのに対し、抹茶を点てたことがある人は29.6%、飲用頻度「年1回未満」が72.8%で、数量ベースでは加工・ラテ用途が飲用を大きく上回ると推定される（[日本経済新聞 2015年](https://www.nikkei.com/article/DGXMZO89689800U5A720C1I00000/)）。海外でも農林水産省は輸出増の中身を「ラテやスイーツ等の食品原料となる抹茶を含む粉末状茶」と説明している（[農林水産省 2025年輸出実績](https://www.maff.go.jp/j/press/yusyutu_kokusai/kikaku/attach/pdf/260203-1.pdf)）。

販路別では、B2B原料（食品・飲料メーカー向け）、B2B外食（カフェ・チェーン向け）、B2C小売・EC、インバウンド、輸出に分かれ、**2025年は緑茶輸出額720.9億円のうち粉末状緑茶が603.8億円（金額の84%）・8,718t（数量の69%）**を占めた（[Tea Energy](https://teaenergy.co.jp/2026/08/07/%E4%B8%96%E7%95%8C%E3%81%A7%E6%8A%B9%E8%8C%B6%E3%81%AF%E3%81%A9%E3%81%86%E5%BA%83%E3%81%8C%E3%81%A3%E3%81%A6%E3%81%84%E3%82%8B%EF%BC%9F%E8%BC%B8%E5%87%BA%E3%83%87%E3%83%BC%E3%82%BF%E3%81%A8%E6%B4%BB/)）。地理別では米国が約293億円（4,431t）で金額の約4割、次いでドイツ58億円、英国47億円、タイ30億円、台湾26億円である（[JETRO 2026年4月](https://www.jetro.go.jp/biznews/2026/04/6df278496539b9a5.html)）。産地別では「抹茶＝宇治」というブランドイメージと実際の供給構造が乖離しており、下表のとおり鹿児島が量で首位、京都が高級品・ブランドという分業になっている。

## 2. 主な顧客と抱える課題：7セグメントに共通するのは「買えない・高い・本物か分からない」

顧客は大きく7つに分けられ、2024年秋以降は全セグメントが供給不足と価格高騰に直面している。下表にまとめたうえで、セグメントごとの特徴を述べる。

**表2：顧客セグメントと課題**

| セグメント | 属性・特徴 | 主な課題（ペイン） |
|---|---|---|
| (a) 食品・飲料メーカー | 伊藤園、明治など。加工用グレードを大量調達。価格感応度が高い | 原料価格の急騰（秋冬番茶10倍、碾茶1.7〜2倍）、量の確保、中国産への切替圧力 |
| (b) カフェ・外食チェーン | スターバックス、Blank Street、国内のnana's green tea等。ラテ用が中心 | 新規口座が開けない、価格表・リードタイム・MOQの不透明さ、メニュー価格への転嫁 |
| (c) 海外輸入商社・D2C | G.S. Haly、Kettl、Sugimoto USA等。京都系高級抹茶に依存 | 割当（アロケーション）、関税の変動、EUの残留農薬・有機規制、模倣品との競合 |
| (d) 国内消費者（茶道） | 65歳以上が多数、茶道人口は減少傾向 | 1人1缶・週1件などの購入制限、値上げ |
| (e) 国内消費者（若年層・健康志向） | 抹茶そのものの飲用習慣は薄く、ラテ・スイーツ・RTD経由で消費 | 抹茶製品の値上げ・終売 |
| (f) 海外消費者 | 米欧のZ世代・ミレニアル女性が中心 | 価格2倍、グレード表記で品質が判別できない、人気商品の即完売 |
| (g) インバウンド観光客 | 宇治・京都の老舗に集中 | 購入制限・品切れ（供給側のペインは転売・買い占め） |

**(a) 食品・飲料メーカー**は原料高が直撃している。伊藤園は2025年9月に抹茶製品の希望小売価格を48.8〜100.0%引き上げ、「寿榮の昔」30gは2,800円から4,200円（税別）になった（[伊藤園 価格改定のお知らせ](https://www.itoen.co.jp/news/article/76353/)、[LOGISTICS TODAY](https://www.logi-today.com/823850)）。同社の決算説明では**抹茶用の秋冬番茶が3,400円/kgと前年の10倍**に高騰したことが減益要因とされ（[BigGo Finance](https://finance.biggo.jp/news/JP_2593.T_2025-12-10)）、明治は「エッセル スーパーカップ 抹茶」を原料供給不足で2026年2月に製造終了した（[Yahoo!ニュース 山路力也](https://news.yahoo.co.jp/expert/articles/b173fa54dd7e7dc0336b409730614831d9363664)）。**(b) カフェ・外食**では、スターバックス米国が抹茶ドリンクを2023年の4品から2026年2月に通年ラインナップ3倍へ拡大し、直営店のティー売上が70%超増加した一方（[Starbucks Stories 2026](https://about.starbucks.com/press/2026/matcha-is-having-a-moment-with-starbucks-front-and-center/)）、ニューヨークの専門店Kettlは仕入先の多くが価格を前年の約2倍に引き上げ、200缶のロットが約16時間で完売するなど供給制約が最も厳しく出ている（[NBC News](https://www.nbcnews.com/business/consumer/matcha-shortage-higher-prices-tariffs-rcna223111)）。供給業者側の記事が「安定供給」「価格表の提示」を売りにしていること自体が、買い手の最大の不安が供給の継続性であることを示す（[Rikyu Matcha](https://rikyumatcha.co.jp/matcha-guide/us-matcha-prices-2026-stable-supply)）。

**(c) 海外輸入商社・D2C**は、米国輸入業者が2025年産の最高級抹茶を前年比75%高で仕入れ、下位グレードも30〜50%高となった（[AP通信（ABC7配信）](https://abc7ny.com/post/how-matcha-prices-popular-powdered-tea-soar-due-global-demand/17827300/)）。EUではMRLが日本基準より厳しく、2025年7月〜2026年3月にポーランドで日本産茶の残留農薬違反が4件報告された（[抹茶タイムズ EU輸入ガイド](https://matcha-times.jp/2026/06/matcha-import-eu-mrl-guide/01/)）。**(d) 国内の茶道実践者**は、老舗が供給を優先してくれる反面、一保堂が2024年10月に1人あたりの購入点数を制限し、丸久小山園が2025年3月に100g以上の袋・缶の販売を停止するなど入手自体が困難になった（[一保堂](https://www.ippodo-tea.co.jp/blogs/news/matcha_restriction)、[丸久小山園](https://www.marukyu-koyamaen.co.jp/information/news-2956/)）。文化庁の調査では茶道愛好者は65歳以上が多数で減少・高齢化しており、購買力より入手可能性が問題である（[文化庁 生活文化調査](https://www.bunka.go.jp/tokei_hakusho_shuppan/tokeichosa/seikatsubunka_chosa/pdf/93014801_06.pdf)）。

**(f) 海外消費者**は若年女性が中核で、Brightfield Groupによれば抹茶ティー／ラテパウダー利用者の64.1%がZ世代とミレニアル（[Flavor Dynamics](https://flavordynamics.com/from-trend-to-teacup/)）、Peet's Coffeeでは抹茶消費者の3分の2がミレニアル／Z世代である（[Nation's Restaurant News](https://www.nrn.com/beverage-trends/matcha-appeals-to-younger-health-conscious-restaurant-consumers)）。彼らの課題は「ceremonial」等の表示では品質が判別できないことで、海外で「茶道で使われる最高等級」と受け取られた結果、高級抹茶から先に売り切れ、国内の茶道関係者の調達まで困難化した（[宇野ゆうかの備忘録](https://yuhka-uno.hatenablog.com/entry/2025/08/27/193553)）。**(g) インバウンド**では宇治の店舗で外国人の大量購入が目立ち、海外通販サイトで老舗の抹茶が通常価格の約3倍で出品され、模倣品も出回っている（[日本経済新聞 2025年5月](https://www.nikkei.com/article/DGXZQOUF14B7P0U5A510C2000000/)）。一保堂は2025年8月に「買い占めて転売を試みる動き」を理由に制限継続と全商品の値上げを告知し（[一保堂 2025年8月1日](https://www.ippodo-tea.co.jp/blogs/news/20250801)）、山政小山園は2026年9月に抹茶缶へのセキュリティシール導入を告知した（[山政小山園 お知らせ](https://yamamasa-koyamaen.pro/info/)）。化粧品・サプリメーカーについては海外調査会社が需要増を指摘するが定量データがなく、国内では主要セグメントとは言い難い（[SDKI](https://www.sdki.jp/reports/global-matcha-market/83040)）。

## 3. サービスの内容：年1回の収穫と5年の成園化が商流全体の時間軸を決める

抹茶の商流は「茶農家→入札市場→茶問屋→（二次加工・商社）→小売・カフェ・輸出」と流れ、その時間軸は原料の生物学的制約に縛られている。碾茶は覆下栽培した一番茶から年1回（4〜5月）作られ、新しい茶園は定植後通常約5年（大苗でも3年）で初収穫、改植は20〜30年に1度しかできない（[静岡県志太榛原農林事務所](https://www.pref.shizuoka.jp/sangyoshigoto/norinjimusho/shidahaibaranorin/1063822.html)、[三重県農業研究所](https://www.pref.mie.lg.jp/fukyuc/hp/31632030333.htm)）。長期被覆は樹勢低下や翌年以降の収量減を招くため、長崎県は碾茶と玉緑茶を隔年交互に生産する方法を検証している（[JA全農 Green Report](https://www.zennoh.or.jp/greenreport/pdf/672/Gr672_03.pdf)）。この「年1回収穫・新植3〜5年・被覆による樹勢低下・碾茶炉という専用設備・高齢化」の5要因が重なり、**需要急増に対して供給は数年単位でしか反応できない**。

年間カレンダーは、3〜4月に被覆開始（20日以上）→4月下旬〜5月に一番茶摘採→直ちに蒸熱・碾茶炉で乾燥し「荒碾茶」→5月中旬に茶市場で入札（京都は2026年5月13日が初入札）→問屋が落札後に低温保管・熟成→注文に応じて仕立て（茎・葉脈除去）・合組・石臼挽きまたは粉砕→包装、という流れになる（[埼玉県 てん茶Q&A](https://www.pref.saitama.lg.jp/documents/283937/tencha_qa.pdf)、[食品新聞 2026年5月21日](https://shokuhin.net/145060/2026/05/21/inryou/inryou-inryou/%E6%97%A5%E6%9C%AC%E8%8C%B6/)）。新茶の入札が5月なので、問屋・輸出業者の新年度価格は6〜8月に改定通知される（丸久小山園7月1日改定、山政小山園8月1日改定、Sugimoto USAの価格改定通知）という季節性がある（[茶の三楽園](https://tea-sanrokuen.com/en/yamamasa-koyamaen-matcha-price-revision-2026/)、[Sugimoto USA Wholesale](https://wholesale.sugimotousa.com/pages/notice-of-price-adjustment)）。

商流の登場人物は、①茶農家・JA系共同製茶工場（荒碾茶まで）、②入札市場（JA全農京都「宇治茶流通センター」、静岡茶市場、鹿児島茶市場）または相対取引、③茶問屋（京都の丸久小山園・山政小山園・一保堂・福寿園・森半、愛知西尾のあいや、静岡の伊藤園など）、④二次加工・OEM（食品メーカー向け粉末、日本抹茶輸出機構のような輸出専業）、⑤商社・輸出業者、⑥海外輸入業者（G.S. Haly、Sugimoto USA、Tezumi等）、⑦小売・カフェ・ECである。鹿児島県は碾茶生産量全国1位でありながら「県内で生産された荒茶の多くが県外で最終製品に加工・販売」されており、付加価値が産地から流出している（[鹿児島県](https://www.pref.kagoshima.jp/ac11/kensei/keikaku/chihousousei/documents/130219_20260908133044-1.pdf)）。段階ごとの価格倍率を表3に示す。

## 4. 市場規模：輸出は6年で5倍、国内は推計しかなく、世界推計は1.5倍の幅がある

## 6. 顧客の獲得経路：カフェのメニューが最大の「無料広告」、B2Bは「安定供給」そのものが訴求点

B2Cの集客エンジンは、TikTok／Instagramでの「見栄え（緑色・レイヤー）」に支えられたZ世代発の拡散と、カフェチェーンによるフレーバー抹茶ラテの季節投入である。Blank Streetはロンドンのミクソロジストが作ったブルーベリー抹茶がバイラル化したのが転機で、毎シーズン数種の新抹茶ドリンクを投入し、マーケティング部門は各ドリンクに「架空のペルソナ」とムードボードを設定している（[CoffeeTalk](https://coffeetalk.com/daily-dose/for-roasters-retailers/06-2025/107767/)）。英国ではSquareの決済データで2025年夏の抹茶売上が前年比+114%、抹茶を提供するカフェは2025年に1,096店と約3倍になった（[City AM](https://www.cityam.com/green-is-good-how-has-blank-street-taken-over-london/)、[Balance Journal](https://balancejournal.co/food-drink/matcha-uk-statistics)）。Google Trendsの「Matcha powder」検索関心は2025年8月に正規化値94でピークを付けており（[Accio](https://www.accio.com/business/matcha_trend)）、TikTokの「#matcha」再生数は出典により1.6億回から160億回まで二桁のばらつきがあるため【要確認】、引用には注意が必要である（[Suzy](https://www.suzy.com/blog/matcha-magic-capitalizing-on-the-fast-growing-functional-drink-trend)）。セレブ経由の訴求としては、Zendaya、Dua Lipaらが抹茶スムージーを飲む姿が「cool-girl wellness aesthetic」として定着し（[The Week](https://theweek.com/culture-life/food-drink/matcha-tea)）、YouTuberのEmma Chamberlainが立ち上げた「Chamberlain Coffee」は抹茶を主力にTargetやWalmartでの小売展開に至った（[The Watchdog](https://thewatchdogonline.com/matchas-social-impact-from-pop-culture-to-performative-wellness-trends-39006)）。米国小売ではWhole FoodsがDōMatcha、Rishi、Matchaful、Aiyaを扱い、Trader Joe'sは自社PB抹茶を販売している（[KnowYourMatcha](https://knowyourmatcha.com/brands/usa)）。

日本国内では、老舗は広告よりも「行列・季節限定・転売報道」自体が集客装置となっており、中村藤吉本店は平日でも整理券が必要、伊藤久右衛門は秋限定の抹茶パフェで来店動機を反復創出している（[Kyotopi](https://kyotopi.jp/articles/rR4Ek)、[@Press](https://www.atpress.ne.jp/news/544417)）。越境ECでは一保堂やO-Cha.comが米国関税撤廃（2025年11月）を自社ブログで顧客告知するなど、関税コミュニケーション自体が集客要素になっている（[一保堂 米国](https://ippodotea.com/blogs/ippodo-tea-blog/november-removal-tarrifs)）。ASEANについてJETROは2026年に「抹茶ブームを経て本格的な普及段階」と評価し、2025年の輸出量はASEAN向け2,495tがEU向け1,938tを上回った（[JETRO 地域レポート 2026年5月](https://www.jetro.go.jp/biz/areareports/2026/d7cf7db2e5a71454.html)）。

B2Bの獲得経路は展示会・商談会・調達窓口・認証が中心である。JETRO大阪商社商談会（2026年1月）では抹茶を関心商材に選定した商社8社で25件の商談が成立し（[JETRO 2026年2月](https://www.jetro.go.jp/biznews/2026/02/cec5365ad6fcd6f2.html)）、「“日本の食品”輸出EXPO」では日本抹茶輸出機構（JMEX）が業務用抹茶の調達窓口として世界60カ国のバイヤーと商談した（[JFEX](https://www.jfex.jp/jpfood/ja-jp.html)）。JMEXは「国内80社直結×40カ国輸出」の安定調達窓口として、仕入れ難に直面するバイヤーを集めている（[PR TIMES JMEX](https://prtimes.jp/main/html/rd/p/000000012.000149434.html)）。供給制約下では「安定供給できること」自体がB2Bの最大の訴求点であり、複数産地（鹿児島を含む）からの調達ポートフォリオを示せる事業者が商談で優位に立つ。認証面では、米国向け輸出茶の64.9%、EU・英国向けの75.3%が有機栽培茶であり（[LinkGlobal](https://www.linkglobal.jp/post/japan-tea-export-us-eu-organic)）、欧米向けでは有機が事実上の標準になっている。さらに**2026年7月10日に「日本茶」がGI登録**され、国産茶葉を国内で加工・袋詰めまで行った不発酵茶（碾茶を含む）が対象となった。申請主体は日本茶業中央会で、背景には中国産「宇治抹茶」模倣品がある（[農林水産省 2026年7月10日](https://www.maff.go.jp/j/press/yusyutu_kokusai/chizai/260710.html)、[食品新聞 2026年5月13日](https://shokuhin.net/144555/2026/05/13/inryou/inryou-inryou/%E6%97%A5%E6%9C%AC%E8%8C%B6/)）。GIマークを前提に「国産・国内加工・袋詰め」を可視化するパッケージが、真正性を訴求する差別化マーケティングの中核になる。

獲得コストについては抹茶ブランド固有の公開データがなく、一般的なD2Cベンチマーク（米国の混合CAC中央値約70〜115ドル、Meta 42ドル・Google 38ドル・TikTok 51ドル、マイクロインフルエンサー30〜50ドル、LTV:CAC目標3:1）しか得られなかった（[Hycos](https://www.hycos.ai/benchmarks/dtc-customer-acquisition-cost/2026)、[EightX](https://eightx.co/blog/average-cac-by-channel)）。抹茶D2Cは単価が高く定期購入との相性が良いため、サブスクでLTVを伸ばしてCACを回収する設計が標準となる。

## 7. 市場動向（PEST）：政策は「量」から「有機・高付加価値」へ、関税は制度が目まぐるしく変転

**Political（政治・規制）**では、農林水産省が2025年4月改定の基本方針で主軸を国内消費から輸出へ転換し、2030年輸出数量1.5万t・金額810億円を目標に碾茶転換と有機栽培を推進、米国・EU・ASEANを重点市場とした（[農中総研 2025年7月](https://www.nochuri.co.jp/report/pdf/nri2507re2.pdf)）。碾茶加工施設は「強い農業づくり交付金」「産地生産基盤パワーアップ事業（補助率1/2以内）」等の対象として静岡・鹿児島・三重・京都・埼玉で増加しており（[農中総研 2026年1月](https://www.nochuri.co.jp/report/pdf/nri2601re3.pdf)）、自治体では浜松市が碾茶用苗木・被覆資材に1/3以内を補助、鹿児島市が抹茶増設企業立地促進補助金を設けている（[浜松市](https://www.city.hamamatsu.shizuoka.jp/noushin/20260616.html)、[鹿児島市 PR TIMES](https://prtimes.jp/main/html/rd/p/000000123.000100148.html)）。ただし碾茶転換は煎茶供給減と煎茶高騰という副作用を生み、2025年の製茶業の休廃業・解散は13件と過去最多になった（[帝国データバンク](https://www.tdb.co.jp/report/industry/20260306-tea25y/)）。

**Economic（経済）**では需要超過が支配的で、京都の碾茶初入札平均が2年連続約1.7倍、丸久小山園の仕入れ単価は2025年に2〜2.5倍となり「過去にない異常な高騰」と表現された（[丸久小山園](https://www.marukyu-koyamaen.co.jp/information/news-3069/)）。煎茶も碾茶転換の波及で高騰し、静岡では一番茶（煎茶用）に買い手がつかない事態と茶価高騰が併存する二極化が起きている（[食品新聞 2026年5月2日](https://shokuhin.net/144065/2026/05/02/inryou/inryou-inryou/%E6%97%A5%E6%9C%AC%E8%8C%B6/)）。インバウンド消費9兆4,549億円は宇治等の実店舗集客を支えるが、2025年12月の中国市場が−45%と国別依存リスクも示した（[トラベルボイス](https://www.travelvoice.jp/20260120-159109)）。農業簿記データでは茶農家の世帯農業所得が2022年約492万円から2024年約558万円へ増加しており、ブームの恩恵は一部農家には及んでいる（[農業利益創造研究所](https://nougyorieki-lab.or.jp/kind/14986/)）。

**Social（社会）**の最大の特徴は「海外ブーム×国内空洞化」の非対称である。海外では抹茶が「クリーンカフェイン・ウェルネス・美学」としてZ世代に受容され、「Gen Zのアボカドトースト・モーメント」と評される一方（[BeverageDaily](https://www.beveragedaily.com/Article/2025/12/04/gen-zs-avocado-on-toast-moment-making-matcha-mainstream/)）、国内では1世帯当たりリーフ茶購入量が2008年比約3割減、首都圏の20代男性の8割以上が自宅に急須を持たず（[ITmedia](https://www.itmedia.co.jp/business/articles/2406/24/news010.html)）、茶の基幹的農業従事者の60歳以上比率は2010年67%→2020年74%に上昇した。裏千家の茶人が「抹茶が日本のものじゃなくなる未来」を警告するなど、文化的危機感も高まっている（[Business Insider Japan](https://www.businessinsider.jp/article/2604-15-the-crisis-of-japanese-matcha/)）。「真正性」への関心（産地・品種表示、GI）は、供給不足下で中国産・簡易碾茶が増えることへのカウンターとして今後強まる。

## 8. 収益構造：原料高のダメージは川上に集中し、カフェは粗利8割で最も転嫁しやすい

抹茶の原価は原料碾茶の相場にほぼ支配される。農家段階では労働費が生産費の4〜5割を占め（[農林水産省 生産費データ](https://www.maff.go.jp/j/seisan/sien/sizai/s_cost/pdf/data4.pdf)）、長崎県の試験では碾茶の製茶歩留まり（生葉→荒茶）は15%、荒茶製造コストは碾茶208円/kgに対し蒸し製玉緑茶147円/kgと高く、碾茶一番茶の平均単価4,230円/kg（令和3年度）という条件で、碾茶と玉緑茶を隔年交互に生産するほうが4か年合計の「粗収益−製造コスト」が16%高かった（[長崎県 R3成果情報](https://www.pref.nagasaki.jp/e-nourin/nougi/theme/result/R3seika-jouhou/fukyu/F-03-47.pdf)）。設備投資は資本集約的で、JA鹿児島県経済連の県内最大規模の抹茶加工施設は年150t規模で建設費約35億円の見込み（2027年12月操業予定）【要確認：複数施設合計の可能性】（[南日本新聞](https://373news.com/news/local/detail/211186)）、静岡の丸山製茶は碾茶製造に数億円規模の設備投資が必要と説明している（[livedoorニュース](https://news.livedoor.com/article/detail/30270894/)）。製粉段階では、碾茶相場14,127円/kgに対し歩留まりを仮に90%とすると抹茶の原料原価は約15.7円/g、30g缶で約470円となり、2024年の3〜4倍である。小売価格改定（丸久小山園1.5〜1.6倍）はこれをなお吸収しきれていない可能性が高い。

料金体系は、小売では一保堂の20g箱が800〜15,000円（税抜）と約19倍の幅があり、海外ECでは同30g箱が23〜42ドルと出典によりばらつく（[Mizu Matcha](https://mizumatcha.myshopify.com/products/matcha-ikuyo-ippodo-30g-box)）。業務用はカフェ向けラテグレードで約80ドル/kgが目安で、B2Bでは固定価格の年間契約が原料相場の年率1.7〜2.6倍の変動下では供給側にとって極めてリスクが高いため、Blue Farmの「MatchaaS」（契約企業ごとに専用茶畑を確保）や伊藤園の全量買取契約栽培といった「圃場単位の契約」が原料固定化の代替手段として台頭している（[LNEWS 2026年9月11日](https://www.lnews.jp/2026/09/s0911504.html)）。サブスクでは、TeaRoomがB2B製造受託・原料卸・企業研修で稼ぎつつD2C「YOU IN」をサブスク中心で展開し（[起業ログ](https://kigyolog.com/interview.php?id=198)）、Cuzen MatchaはB2B向け「Matcha Maker for Business」を投入した。

カフェ段階の損益構造は原料比率の低さが特徴で、抹茶ラテ1杯は抹茶3g×約80ドル/kgで粉コスト約0.24ドル、ミルク0.30〜0.90ドルを含め製造原価0.80〜1.45ドル、粗利率は抹茶ラテ82〜85%（エスプレッソ系72〜75%）、人件費・家賃込みの純利益率は抹茶専門店で15〜25%とされる（[first-agri.jp](https://first-agri.jp/matcha/columns/039)、[Matcha Sunday](https://matchasunday.com/blogs/learn/matcha-drink-profit-margins-for-cafes-and-boba-shops)）。ただしこれらは抹茶供給業者のブログであり楽観的バイアスに注意が必要である。カフェにとって抹茶粉コストは1杯30〜150円程度で売価の数%〜十数%にとどまるため価格転嫁しやすく、Squareの決済データでは2025年に米国の抹茶ラテ平均価格が上昇しても顧客は買い続けた（[Grey Journal](https://greyjournal.net/hustle/grow/how-to-start-a-matcha-business-2026/)）。原料高騰のダメージは川上（製茶業者・問屋）に集中している。

参入障壁の最大のものは原料碾茶の入手であり、問屋の販売制限と入札平均14,127円/kgという相場のもとでは、新規参入者が問屋から安定的に高級抹茶を仕入れることは2025〜2026年には事実上困難である。したがって現実的には「茶園を自社で持つ／契約する」か「業務用グレード（鹿児島・静岡・中国産）で始める」かの二択になる。資本の流れを見ると、海外（米国）では「カフェ／ブランド」にVC資金が集まり（Blank Street約1.05億ドル）、日本では「川上（茶園・製茶）」に商社・JA・大手飲料の事業資金が集まるという対照があり、海外VCを狙うなら消費者ブランド、国内で事業会社資金を狙うなら原料供給の垂直統合モデルが資金調達上は整合的である（[FinSMEs](https://www.finsmes.com/2026/08/blank-street-raises-approx-105m-in-funding.html)）。日本国内の抹茶専業スタートアップで10億円超の大型調達は確認できなかった。

公的支援は「産地生産基盤パワーアップ事業（補助率1/2以内）」「強い農業づくり交付金」「農畜産物輸出拡大施設整備事業」が碾茶関連で多用されており（[農林中金総研 農林金融 2026年7月](https://www.nochuri.co.jp/report/pdf/n2607re3.pdf)、[補助金ポータル](https://hojyokin-portal.jp/columns/nogyo_hojyokin_guide)）、補助率1/2を前提にするとJA鹿児島型（約35億円）の半分は公費、大五通商型（約10億円）でも数億円の補助が得られ得る。ただし補助事業は産地（JA・農業法人）が受け皿となるケースが多く、異業種の新規参入者は農業法人設立または産地JAとの共同事業体の形を取る必要がある。後継者不在の老舗問屋・製茶業の買収は、2025年の廃業過去最多と売り案件の低価格（250万円以下の案件も）を踏まえると、資本力のある異業種にとって最速の参入経路である（[TRANBI](https://www.tranbi.com/buy/detail/?id=22425)）。

以上を踏まえた推奨ポジショニングは次のとおりである。第一に、**業務用の「量」で中国産と正面から戦う戦略は避ける**べきで、中国産の単価8〜11米ドル/kgに対し日本産36米ドル/kg超という差は、ラテ・菓子原料で代替圧力が強いことを意味する。第二に、**川上（①②）と川下（③④⑥）を組み合わせたハイブリッド**が最も防御力が高い。たとえば鹿児島・静岡の碾茶工場や老舗問屋をM&Aで取得して原料口座を確保し、有機JAS＋EU有機を前提に茶園を設計し、GI「日本茶」マークとトレーサビリティ（産地・品種・製粉方式の明示）で欧米の「真正性」志向に応え、国内ではインバウンド向けの体験型店舗（石臼挽き・茶室）で高単価を取る、という構成である。第三に、**時間軸を2段階で設計**する。2026〜2027年は供給逼迫が続くため既存煎茶園の碾茶化と簡易碾茶・鹿児島産で業務用を立ち上げ、2028年以降に新植・有機転換分が寄与する段階でプレミアム帯に移行する。第四に、**ほうじ茶ラテなど「次の抹茶」をポートフォリオに組み込む**。ほうじ茶はサプライチェーンの逼迫度が抹茶より低く、海外検索が+173%と伸びており、抹茶一本足のリスクヘッジになる（[Brik.ly](https://www.brik.ly/reports/cafe-drinks-trend-report-2026/)）。

## 結論

本調査が示す最も重要な洞察は、抹茶市場の成長がすでに「数量の成長」から「単価の成長」に変質しており、2026年上期の輸出が数量+19.6%・金額+99.1%という構図は、ブームの持続ではなく供給制約の表れだという点である。京都の碾茶価格が2年で約3倍になっても増産が追いつかず、同時に中国産の輸入が倍増して業務用の隙間を埋めている以上、2027年以降の市場は「日本産高級品の高価格維持」と「中国産・簡易碾茶による業務用の代替」が並走する二層構造に固定化していく。この構造下で価値を持つのは「抹茶を売る能力」ではなく「碾茶を確保する能力」であり、商社・JA・大手飲料が2025〜2026年に一斉に川上へ投資した事実がそれを裏付けている。

新規参入を検討する事業者にとっての示唆は、参入の問いを「どのチャネルで売るか」から「どの産地のどの原料を、どの契約形態で何年分押さえられるか」に置き換えることである。2026年7月の「日本茶」GI登録、欧米で有機が事実上の標準になったこと、「真正性」志向の高まりは、日本産にとって中国産が模倣しにくい差別化軸を制度面から後押ししている。一方で、抹茶ラテのSNSシェアが成熟期に入り、ほうじ茶が「次の抹茶」として台頭している兆候は、抹茶一本足の事業設計への警告でもある。供給が追いつく2028年以降に備え、原料・認証・ブランドの三点を同時に積み上げられる参入者だけが、ブームの終わりを生き残る。
