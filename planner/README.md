# 2026-27 デジタル手帳｜9月始まり（2026.09 → 2027.12）構成仕様

Notion「2026 Life Wiki｜静かな豊かさの光庭」配下に作成した手帳の設計書。
本体はNotion。この文書は構成の正本（何をどう組んだか）だけを残す。個人の予定・記念日・予約情報はここには書かない。

作成日: 2026-09-23（水）

## 役割分担

| 層 | 場所 | 扱うもの |
|---|---|---|
| 今日 | 朝ハブ・夕ハブ・TODO.md（既存） | 3大タスク、繰越、習慣チェック、方位盤、マーケット |
| 週・月・年 | この手帳（Notion） | 大きな石、プロジェクトの次の一手、月次定例、振り返り |

手帳には日次の細かいタスクを書かない。朝ハブが「週ごとのメモ」を読んで毎朝の提案を出す前提。

## ページ構成

```
📔 2026-27 手帳｜9月始まり
├─ トップ（役割・ナビ・この1年の位置・5つの流れ・183日カウンター・回し方）
├─ 🗓 年間イベント（DB）      … 旅・ツアー・手続き・記念日・期限・節目
├─ 📋 プロジェクトボード（DB） … 進行中プロジェクトを1画面で
├─ 📅 月間ページ（DB）        … 16ヶ月分の見開き
├─ 🔁 定例と習慣              … 日・曜日・月・年の定例を1枚に
├─ 📝 週の型                  … 毎週日曜の夜に10分で使うテンプレ
└─ 🔍 振り返りの型            … 月末・四半期・半年のテンプレ
```

## データベース定義

### 🗓 年間イベント
| プロパティ | 型 | 選択肢 |
|---|---|---|
| 予定 | タイトル | |
| 日付 | 日付（範囲可） | |
| 種別 | セレクト | 旅・移動／ツアー・事業／法人・手続き／打合せ・イベント／記念日・家族／期限／節目 |
| 流れ | セレクト | 伝える／旅／学び／土台／共創／暮らし |
| 確定度 | セレクト | 確定／予定／検討中 |
| 出典 | セレクト | Googleカレンダー／プロジェクト資料／5年計画／手帳で追加 |
| メモ | テキスト | |

ビュー: テーブル・タイムライン・カレンダー。

### 📋 プロジェクトボード
| プロパティ | 型 | 選択肢 |
|---|---|---|
| プロジェクト | タイトル | |
| 流れ | セレクト | 伝える／旅／学び／土台／共創／暮らし |
| 状態 | セレクト | 🟢 進行中／🟡 仕込み中／🔵 運用中／⬜ 未着手／🔴 止まってる／🕊 受け身／✅ 完了 |
| 次の一手 | テキスト | |
| 次の節目 | 日付 | |
| 節目メモ | テキスト | |

| 関連 | テキスト | ローカルファイル・Notionページの所在 |

ビュー: テーブル・状態ボード・5つの流れボード。

### 📅 月間ページ
| プロパティ | 型 | 選択肢 |
|---|---|---|
| 月 | タイトル | |
| 期間 | 日付（範囲） | |
| 季節 | セレクト | 土台を締める（2026.09-12）／出発の準備（2027.01-02）／ジョージア長期滞在（2027.03-11）／戻って締める（2027.12） |
| テーマ | テキスト | |
| 大きな動き | テキスト | |
| 所在 | セレクト | 京都／ジョージア／移動多め／未定 |
| 月末レビュー | セレクト | 未／記入中／済 |

各月ページの本文は同じ骨格:

1. 今月のテーマ（コールアウト）
2. 🎯 今月の焦点（3つまで・チェックボックス）
3. 📅 固定の予定（カレンダーより）
4. 📋 プロジェクトの節目
5. 🔁 月次の定例（1日・19日・29日・30日・最終日曜）
6. 🗓 週ごとのメモ（月曜始まりの週ごとに見出し）
7. 🔍 月末レビュー（四半期・半年・年末の月は問いを追加）

## 回し方

| いつ | 開く場所 | すること |
|---|---|---|
| 毎朝 | 朝ハブ | 手帳は開かない |
| 日曜の夜 | 今月の月間ページ「週ごとのメモ」 | 週の型で来週を組む（10分）。ボードから「次の一手」を2つだけ持ってくる |
| 最終日曜 | 月間ページ「月末レビュー」＋ボード | EQ月次更新のあとに15分。状態と次の一手を更新し、翌月の焦点を3つ書く |
| 四半期末 | 振り返りの型 | 5つの流れ・5年の航海・183日カウンターを更新（30分） |
| 旅の前 | 年間イベント | 確定度を上げる。旅行まとめの5点セットを作る |
